# 聊天气泡与设置字号

在「设置 → 外观 → 聊天 → 消息展示」开启气泡模式。关闭时使用原有布局，旧配置默认关闭。切换可即时预览；保存后写入本地配置，取消更改恢复已保存值，恢复默认外观会关闭气泡模式。设置搜索支持“气泡模式”和“消息展示”。桌面与聊天设置共用“外观”入口，页内按桌面、聊天分组；恢复默认外观同时重置这两组，取消更改可恢复已保存的配置。

配置字段为 `appearance.chatkit.messagePresentation`，值为 `transcript` 或 `bubbles`。主进程校验并持久化，渲染端在初次创建和后续 `setOptions` 时转成 `messagePresentation.mode`。更新保留原来的 ChatKit 节点、认证回调与会话，不触发重新登录。

本地开发需要使用支持气泡模式的 ChatKit UI；只更新 Desktop 不会让旧的远端 iframe 获得新能力。更新本次代码后需重启 Desktop 主进程，以加载新增配置字段的校验和保存逻辑。不要只依赖渲染页面的热更新。

设置页字号调整以默认桌面基准 16px 为参照：页面标题 32→24px，侧栏标题 24→20px，分组标题 18→16px，导航与字段标签 16→14px，辅助说明 14→13px。继续使用 rem，保留用户选择的基准字号；未改动聊天字号、桌面全局默认字号或窗口缩放。
