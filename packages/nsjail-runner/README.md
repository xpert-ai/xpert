# Xpert NsJail runner image

This private workspace package owns the Docker image version for
`xpert-nsjail-runner`; it is not published to npm. The runner and Dockerfile remain
in [`.deploy/nsjail-runner`](../../.deploy/nsjail-runner).

Use a Changeset for `@xpert-ai/nsjail-runner` to request a candidate build. See
[application image releases](../../.deploy/application-images/README.md) for the
candidate and stable release process.
