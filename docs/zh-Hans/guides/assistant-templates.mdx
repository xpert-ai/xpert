智能体模板（Assistant Template）把可复用的智能体定义和初始化要求交付给用户。导入后，用户在可编辑工作空间中获得独立的 Assistant；模型、账号、偏好和业务数据由目标环境管理。Web 与 Desktop 共用服务端安装和生命周期契约。

模板作者请阅读[模板编写与打包](/zh-Hans/guides/assistant-template-authoring)；平台开发者请阅读[模板生命周期架构](/zh-Hans/architecture/assistant-template-lifecycle)。

## 目录与来源

模板市场和“发现与添加”按照以下来源展示，并在分页前完成排序：

| 顺序 | 来源                        | 内容                                             |
| ---- | --------------------------- | ------------------------------------------------ |
| 1    | 智能体插件（Agent Plugins） | 文件配置包声明的 Assistant Templates             |
| 2    | Xpert 插件                  | 原生插件贡献的模板；应用关联模板通过应用入口管理 |
| 3    | 系统内置                    | 平台随附的 Xpert Templates                       |
| 4    | 共享模板                    | 用户发布且当前访问者有权查看的模板               |

来源数量按当前可见的智能体模板统计，排除不属于该目录的应用资源和非智能体条目。分类列表及数量跟随所选来源；搜索进一步筛选卡片，不把来源总数改成搜索命中数。数量在分批加载期间逐步更新，不是产品的固定模板总数。

目录使用轻量摘要，头像按需加载，完整定义仅在详情或安装时读取。切换组织或语言后，旧请求不能覆盖新范围的目录。

## 详情与导入

点击模板卡片进入详情；“使用模板”直接进入配置。详情从模板实际声明生成四类能力介绍：

| 页签     | 说明                                   |
| -------- | -------------------------------------- |
| 记忆     | 职责与工作方式、初始知识和首次使用要求 |
| 技能     | 声明的技能与相关工作步骤               |
| 例行任务 | 可配置的自动任务、时间与产出要求       |
| 集成     | 需要的应用、连接器与权限               |

导入流程依次检查目标空间、模型与运行能力、资源依赖和初始配置。用户可以调整新 Assistant 的基本信息。缺少必需且不受支持的能力会阻止安装；需要用户配置的项目会显示后续步骤。

安装过程有持久记录，包含 Assistant 标识、当前阶段、尝试次数和可重试状态。页面刷新、客户端重开后可以恢复查看；重试复用原操作和已创建资源。需要第二个独立 Assistant 时，发起新的安装意图。

“已创建”“已发布”“已授权”“业务可运行”是不同状态。安装成功不保证外部连接已经授权，也不会自动升级其他已安装实例。

## 首次使用、文件与集成

首次引导按用户与 Assistant 保存进度，收集声明的语言、时区等业务偏好，并按完成标准产生首个实际结果。中断后继续既有进度。

模板可声明目录、普通文件及 JSON 台账。初始化使用 `create-only`：创建缺失内容，保留已有业务文件。`user` 数据范围按用户隔离；`shared` 范围供获准的协作者使用。文件范围不能替代空间或业务资源的访问控制。

连接器声明表达“需要哪个服务及哪些权限”，不携带凭据。用户选择目标环境中有权使用的连接，或由有权管理连接的人完成授权。缺失、过期、权限范围不足会分别显示。可选集成可以跳过，其工具不会因此获得执行资格；必需集成未就绪时相应业务受限。

业务操作策略在运行时按实际工具名执行 `allow`、`approve` 或 `deny`。审批被拒绝时不调用工具处理器。模板中的自然语言提醒不能替代该策略。

## 例行任务与后台结果

例行任务声明默认关闭。安装模板不会自动开始执行；首次显式配置才建立个人任务，用户还需启用并确认时区和下一次执行时间。同一用户、Assistant 与任务 key 复用同一任务。

当前支持定时任务；事件触发声明尚不能执行，必需的事件任务会阻止就绪，可选的会标记不可用。服务端后台任务不依赖 Web 或 Desktop 保持打开；仅本地可执行的能力不能转为服务端任务，会返回 `LOCAL_RUNTIME_UNAVAILABLE`。

活动记录显示运行、完成、失败和等待审批等状态，未读状态按用户保存，客户端约每 15 秒刷新。这是平台内活动通知，不代表已经提供邮件、短信或操作系统推送。

## 分享与链接导入

发布前检查可移植内容。组织分享仅对获准范围可见；公开分享面向已登录平台用户，并非匿名访问。撤销分享会停止新的发现与导入，不删除别人已经创建的 Assistant。

发布使用白名单投影，排除账号绑定、用户偏好、运行记忆、业务文件、任务启用状态和实例范围标识。自由文本仍需作者检查，不能假定所有敏感内容都能被自动识别。当前支持的图和中间件之外的配置会阻止发布，不承诺任意工作流都能无损转换。

桌面链接打开模板预览，再由用户确认导入。登录前的待处理链接可以恢复，并重新校验来源和访问权；不会在打开链接时自动安装。

## 升级与恢复

升级比较模板基线、用户当前配置和新来源，按展示信息、指令、运行图配置及模板要求检查差异。用户处理冲突后先保存草稿，再显式发布；过期预览会被拒绝，必须重新检查。

升级保留 Assistant 身份、对话、业务文件、用户偏好和仍然兼容的连接选择。已有任务定义或数据范围不兼容时阻止自动合并；新增任务保持暂停。原生插件来源可通过明确的迁移预览转到 Agent Plugin 来源，不会静默切换依赖。

中断操作可以恢复；有操作快照时可以恢复之前的配置。回退不撤销已经发生的外部写入或业务文件变更，也不是任意历史版本的备份服务。

## 模板系列与适用范围

插件仓库 `agent-plugins/assistants/` 提供 90 个分类角色包和统一系列头像，包含 Office Ops。Office Ops 使用同一文件配置结构，组合七个技能、五个 JSON 台账和三个默认暂停的例行任务。模板展示名称、描述与分类支持国际化，内部技能文档不要求翻译。

这套能力支持在 Xpert 中交付同类业务助手，不直接解析第三方私有模板格式。模板所依赖的模型、沙箱、中间件和连接器必须由目标平台提供。

## 验收范围

平台功能及 Web/Desktop 测试环境验收已于 2026-10-14 经用户确认通过。真实供应商账号的验证仍应按目标环境单独执行：Notion、Slack、Linear、Google Sheets、Gmail、Calendar 的真实授权和业务读写不由通用流程验收代替。macOS 开发环境的桌面链接验证也不代表 Windows、Linux 或签名安装包已验证。
