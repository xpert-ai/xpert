生长树是[对话脉络](/zh-Hans/guides/conversation-map)中的图形视图，用连续收细的枝条展示讨论路径和 Agent 执行记录。它包含两层：**讨论脉络**展示对话如何分叉，**本轮执行**展示一条回复背后的 Agent、活动组和工具调用。

## 使用流程

1. 在 Assistant 工作台打开**对话脉络**，选择项目和**生长树**页签。
2. 在可搜索的对话选择器中选择对话，再选择要跟随的讨论分支。列表支持服务端搜索和滚动分页，重新打开时保留已加载结果。
3. 选择问答叶片，查看问题、回复及来源。尚未得到回复的问题也可以查看。
4. 对具有执行记录的回复选择**查看本轮执行**，进入该回复的 Agent 树。
5. 选择工具叶片或打开**活动记录**，查看状态、可用输入输出和记录详情。
6. 使用**返回讨论脉络**回到讨论层，或选择**在聊天中定位**打开原始消息。

## 主干、分枝与叶片

| 图形 | 讨论脉络                     | 本轮执行                                              |
| ---- | ---------------------------- | ----------------------------------------------------- |
| 主干 | 当前选择分支的消息祖先路径   | 该回复对应的根 Agent 执行                             |
| 粗枝 | 从共同消息祖先分出的讨论路径 | 具有明确父子归属的子 Agent 或外部调用                 |
| 细枝 | 一轮问答的展示枝条           | 同一 Agent 内连续、同类型的活动组，每组最多 24 条记录 |
| 叶片 | 一轮用户问题及回复           | 一个有稳定标识的工具调用；更新和结果合并到同一片叶上  |
| 端点 | 分支名称和记录状态           | Agent 名称、执行状态、可用耗时及独立的业务结果        |

执行层还保留最终文字回复作为**回答**事件。根 Agent 始终是主干，不因子 Agent 活动较多而改变身份。

**横向位置表示记录先后，不是按耗时等比绘制的时间轴。** 不同记录源没有统一时钟，枝条长度不能用于比较 Agent 运行耗时，也不能据此计算等待时间。存在明确耗时记录时，端点和详情会展示该数值。

枝条粗细参考尚未分出的下游活动量，包含委派子树，并从根部向末端连续收细；子枝连接处不会比父枝更粗。叶片朝向随所在曲线的局部方向调整。

## 分叉如何形成

### 讨论分叉

讨论树沿各可见分支的最新消息回溯祖先关系。共同前缀只出现一次，祖先路径实际分离时才产生分叉。

**显示历史版本**控制编辑消息产生的旧分支；当前选择的分支始终保留，空分支也可以显示。分叉后的首条回复使用真实继承的问题作为上下文。

独立对话具有自己的树。具有可访问来源时，工具栏提供**来源对话**入口；副本不会被画成源对话的实时子分支。

### Agent 委派与工具活动

执行树从所选回复的根执行读取后代，父子关系来自明确的执行记录。具备对应工具调用标识时，子枝从父干上的调用点平滑分出。该调用点可以选择，但不会额外重复成一根活动细枝。

只有父子关系、缺少调用点记录时，用**虚线分枝**表示。缺少可靠 Agent 归属的活动会明确标为未归属，不根据名称相同、内容相似或时间接近补造关系。

同一 Agent 中具有相同工具调用标识的更新合并为一条记录；外部活动使用稳定记录标识合并，并保留首次出现的顺序。具有不同调用标识的重试是不同叶片，界面不推测它们之间的重试关系。

## 图例、状态与业务结果

图例位于左上方缩放控件下方，以“图标 + 标签”的竖排浮层展示，可展开或收起。讨论层与执行层分别显示适用的结构说明。

| 活动符号 | 含义     |
| -------- | -------- |
| 三角形   | 提问     |
| 圆形     | 探索     |
| 方块     | 修改     |
| 菱形     | 验证     |
| 双圆     | 回答     |
| 虚线圆   | 其他活动 |

活动类别来自记录中明确的类型字段。旧记录没有类型时显示**其他活动**，不会按工具名称推测用途。失败调用显示叉号；未知、运行中、待执行、等待中或取消中的工具调用使用空心标记，并提供文字状态。

**执行完成与业务通过分别展示。** 例如，验证 Agent 可以正常完成执行，但业务结果仍是“发现缺口”。业务通过或失败只有在记录提供明确结果时才显示，不从执行成功推导。

## 画布与活动记录

画布占据内容工具栏下方的剩余工作区，优先保留横向空间。活动面板默认隐藏，点击叶片或**活动记录**后从右侧滑出，以圆角卡片浮在画布上；画布仍可交互。

| 操作              | 行为                                                                              |
| ----------------- | --------------------------------------------------------------------------------- |
| 缩小 / 放大       | 调整树图缩放；鼠标悬停和键盘聚焦显示简短 Tooltip                                  |
| 适配并居中 / Home | 重置平移和缩放，以实际图形及文字边界居中，通常保留 32px 边距，自动放大最多 1.5 倍 |
| 拖动画布 / 方向键 | 平移树图                                                                          |
| 选择叶片          | 高亮所属路径，并打开活动记录详情；叶片支持 Enter 或空格选择                       |
| 选择活动记录      | 同步选中图中叶片；仅在叶片不可见或被面板遮挡时平移，不改变缩放                    |
| 在图中定位        | 收起活动面板并定位所选叶片                                                        |
| 折叠图中分枝      | 隐藏相应图形后代；活动列表仍保留记录，列表展开状态独立管理                        |
| 关闭面板 / Esc    | 收起面板，保留选中项，并将焦点返回活动记录入口                                    |

活动列表和详情分别滚动。普通打开或关闭面板不重置用户的缩放和平移；宽屏面板展开时，主动点击**适配并居中**会使用面板外的可见区域，关闭面板后适配基准恢复为完整画布。窄屏始终按完整画布适配。

缩放控件、图例和活动面板跟随宿主容器圆角，内部条目跟随条目圆角，直角主题同样生效。界面支持中英文、浅色和深色主题；减少动态效果的系统设置会关闭滑入动画。

## 刷新与状态恢复

存在活跃记录时，视图约每 5 秒重新读取一次受限快照；请求串行执行，后台页面暂停轮询。自动刷新保留选中记录和分枝折叠状态，过期响应不会覆盖新选择。

宿主保存视图模式、项目以及对话、分支和回复位置。刷新后可回到原来的讨论或执行层。切换项目会清理之前的定位信息；手动**刷新**重新读取当前记录，并清理选择器缓存。

## 可见记录与数据边界

查看执行需要先通过 Assistant、项目和对话权限，并确认所选分支属于该对话、回复位于该分支的可见祖先路径。外部活动还需要通过对应调用的访问与绑定有效性校验。

复制的历史执行使用已保存快照，界面会说明其历史属性，不回读源执行的实时活动。输入输出展示经过凭据脱敏和长度限制的公开记录；推理内容、检查点及运行时私有状态不在此视图中提供。

| 范围           | 当前上限或行为                                                     |
| -------------- | ------------------------------------------------------------------ |
| 树图主干与分枝 | 最多 500 条                                                        |
| 活动记录       | 最多 5,000 条                                                      |
| 外部调用明细   | 每次最多检查 40 个调用，每个读取 100 条活动                        |
| 讨论正文       | 最多读取 5,000 条；拓扑校验仍需读取祖先链接元数据                  |
| 大量记录       | 使用有上限的快照和分枝折叠；整体适配后可放大或通过活动列表查看细节 |

达到上限、缺少身份、没有执行记录、详细活动不可用或时间信息不足时，界面显示相应覆盖提示。没有保存的活动无法恢复；旧回复的保存状态不可用时，执行读取可能失败，讨论层仍可使用。布局不会合成缺失的等待区间或完整跨源时间线。

## 集成与兼容

生长树通过现有对话脉络 View provider 读取数据，查询使用 `operation: 'trail'` 和对话标识，并可指定分支、回复及历史版本选项。省略回复标识读取讨论层，指定有权访问的 AI 回复读取执行层。共享数据契约为 `TrailGraph` v1。

该功能使用派生只读视图，无需数据库迁移，活动类型字段兼容旧记录。API 与随包的 remote component 资产需要一起更新。最大化视图中的原消息定位依赖 ChatKit 先显示聊天区再滚动高亮的能力，发布时应包含对应宿主更新。
