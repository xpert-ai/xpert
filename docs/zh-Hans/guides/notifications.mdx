title: '公告与通知中心'
description: '在 Web 和 Bosi 桌面端查看公告、打开任务结果，并按租户发布和管理公告。'
---

打开 Web 或 Bosi 桌面端的**通知中心**，可以查看当前租户的公告、自己的定时任务结果，以及助手发来的业务提醒。入口数字汇总当前快照中的待展示公告和未读通知。需要查找更早的记录时，打开历史列表继续加载。

## 查看公告

新公告可在界面右上角以卡片展示。点击查看详情可展开正文，关闭后可在公告历史中找回。关闭操作会同步到同一账号的另一端；离线时先在本地隐藏，恢复连接后同步。管理员编辑同一条公告后，已关闭它的用户不会再次自动看到这张卡片。

历史按租户和客户端过滤，包含已经生效的公告，也包含已关闭或已过期的公告。管理员撤回后，该公告会从用户历史中移除。

## 打开任务结果

个人定时任务成功完成、结果会话已空闲且仍可访问时，通知中心会出现任务结果。选择结果可回到对应会话。若会话访问权已撤销，结果不再可读。登录或恢复连接后会补齐列表；查看通知不会重新执行任务。

采购交期提醒、代码评审结果和飞书私聊的开关见[助手发件箱](/zh-Hans/guides/agent-outbox)。

## 发布公告

具有 `ANNOUNCEMENT_MANAGE` 权限的管理员在 Web **设置 → 公告**（`/settings/announcements`）中管理当前租户的公告。

1. 新建草稿，填写标题、正文、类别、重要程度、适用客户端和生效时间。可以设置失效时间及 HTTPS 动作链接。
2. 预览后发布。到达开始时间时，选定的 Web 或桌面客户端开始展示。失效后公告离开待展示列表。
3. 在管理列表可编辑内容或撤回公告，并查看修订审计。发布后受众固定；如需改变客户端受众或再次通知已关闭公告的用户，复制为新公告再发布。

同时编辑产生修订冲突时，重新加载最新版本再保存。公告管理权限默认授予超级管理员。
