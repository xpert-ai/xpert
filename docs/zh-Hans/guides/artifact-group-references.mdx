description: '将创作项目中的已发布看板授权给群聊，在工作台查看，并让 Agent 在明确的数据范围内分析。'

群聊可以引用其他项目中已发布的资源。以 Live Dashboard 为例，“库存透视”在创作项目中制作和发布，经营分析群绑定自己的项目；授权并接受引用后，群成员可以在工作台打开同一个看板，也可以在获准的范围内让 Agent 查询和分析数据。

看板仍归属于创作项目。共享不会复制看板、切换群聊项目，或把群成员加入源项目。选择某个 Assistant，也不会自动开放该 Assistant 使用过的项目和资源。

## 开始前

使用包含群聊共享资源功能的 Xpert API、SDK、ChatKit 和 Cloud/Bosi 宿主，以及支持群聊授权的 Live Dashboard 插件。对话分析还要求对应的数据来源支持分析授权。仅安装插件或绑定项目，不会自动授予资源访问权限。

- **分享者**已正常登录，具有源项目管理权限，并且是目标群聊的有效成员。
- **源看板**至少有一个已发布的正式版本。草稿不能通过群聊引用分享。
- **目标群聊**已经绑定项目。群主负责接受授权；其他成员使用已经接受的资源。
- **查看者或提问者**具有相应数据源权限。共享看板定义不等于共享数据源账号或数据库权限。
- **用于对话打开的 Assistant**已加入群聊、开启“资源助手”能力，并使用支持工具调用的模型。

群聊创建、成员邀请和项目绑定参见[群聊](/zh-Hans/guides/group-chat)。看板制作与发布参见[看板生命周期与分享](/zh-Hans/guides/artifacts-dashboard/lifecycle-and-sharing)。

## 从源看板发起授权

1. 在已登录的创作会话中，打开源项目的 Live Dashboard。
2. 打开**团队分享 → 群聊授权**。群聊引用与“分享链接”是不同的分享入口。
3. 选择正式版本和目标群聊。列表显示自己已加入且已绑定项目的群聊；必要时点击**加载更多**。
4. 选择群聊的数据使用方式，按下一节配置。
5. 选择有效期：**1 天、7 天或 30 天**，默认 7 天。
6. 点击**授权给群聊**。这一步发出待接受的授权，群主接受后才可使用。

授权有效期从发起授权时计算，不是从群主接受时计算。源看板的分享面板可以查看授权状态并撤销授权。发起和撤销授权须通过已登录的源创作会话完成；群内打开的共享看板不提供源授权管理入口。

## 配置 Agent 的数据使用范围

### 选择权限级别

| 选项                          | 群内 Agent 可以做什么                                                                              | 适用场景                     |
| ----------------------------- | -------------------------------------------------------------------------------------------------- | ---------------------------- |
| **仅查看看板**（默认）        | 可在具备“资源助手”能力时请求打开看板；不获得共享数据集的查询权限                                   | 成员主要通过界面筛选和查看   |
| **允许 Agent 查询看板数据集** | 查询选中的已发布数据集，返回获准字段和行范围内的数据集结果；不能另加探索性的筛选、分组、聚合或排序 | 根据看板已有结果回答问题     |
| **允许在选定数据集内分析**    | 在选中数据集内追加筛选、分组、计数、求和、最小值、最大值和排序；是否返回未聚合结果单独控制         | 比较工厂、分析结构、查找排名 |

“数据集”是该正式版本声明的查询结果范围，可能已经过聚合。它不代表整个数据库、任意表或任意模型；“数据集明细行”也不必然等于业务原始单据。

### 选择数据集、字段和行范围

选择后两种权限级别时：

1. **勾选数据集**：至少选择一个。无法勾选时，检查分享者的数据授权资格以及数据来源是否支持群聊分享。
2. **保留所需字段**：勾选数据集时默认选中其全部字段，可以取消不需要开放的字段。每个数据集至少保留一个字段。
3. **添加固定行范围**（可选）：选择获准字段并设置“等于”条件，例如某个工厂编码。多个固定条件同时生效；Agent 不能移除这些条件或扩大范围。
4. **决定是否返回明细**：在“允许在选定数据集内分析”模式下，默认只允许聚合结果；需要返回未聚合的数据集行时，勾选**允许返回数据集明细行**。“允许 Agent 查询看板数据集”模式会返回数据集行，没有此开关。
5. **设置每次查询最多返回行数**：可选 **20、50、100**，默认 50。该值是单次结果上限，不是底层数据集的总行数。

切换正式版本后，需要重新选择分析权限和数据范围。数据集、字段和固定条件都以所选版本为准。

这些限制用于 **Agent 的对话分析**。人工打开看板后的交互查询继续使用查看者本人的数据权限；分析表单的字段和行限制不替代人工查看时的数据源权限策略。

### 示例：授权库存汇总分析

假设“库存透视”包含 `inventory_stock_by_plant` 和 `inventory_filter_catalog` 两个数据集：

1. 选择**允许在选定数据集内分析**。
2. 勾选 `inventory_stock_by_plant`，只保留分析所需的工厂、库存数量和库存价值字段。只有确实需要筛选目录数据时，才额外勾选 `inventory_filter_catalog`。
3. 如需限制到某个工厂，在该数据集的实际工厂编码字段上添加固定等于条件。
4. 保持**允许返回数据集明细行**关闭，行数选择 50，有效期选择 7 天。
5. 发出授权，由群主明确接受数据分析权限。

之后可以在群里提问：“请按工厂汇总获准范围内的库存价值，并按价值降序排列。”实际能回答的问题取决于所选字段、数据完整性和提问成员的数据源权限。

## 在群聊中接受与打开

1. 群主进入目标群聊，打开**更多 → 共享资源**。
2. 在**待接受授权**中核对名称、正式版本和数据分析范围。
3. 如果需要对话分析，勾选**接受数据分析权限（不勾选则仅接受查看权限）**，然后点击**接受引用**。
4. 群成员点击资源的**打开**，在 Workbench 中查看看板。

即使源方提供了分析权限，群主不勾选也只接受查看权限。已有的只读授权不会自动升级。之后要增加分析权限或改变其范围，需要源方撤销旧授权、重新发起，再由群主接受。

每个共享引用有自己的工作台标签页；再次打开同一引用会定位已有标签页并保留当前筛选。共享视图提供看板查看和交互查询，不提供源草稿编辑、发布、导出或再次授权。制作过程仍在源项目的创作视图中完成。

## 通过对话打开与分析

### 开启“资源助手”

在创建 Assistant 时选择**资源助手**，或在 Bosi 的 Assistant **编辑资料 → 模型与能力**中开启，并**保存并发布**。此能力默认关闭，要求支持工具调用的模型。配置方式参见[Assistant 能力](/zh-Hans/guides/assistant-capabilities)。

开启后，不需要在每次对话的插件菜单中再次选择它。关闭能力会移除它自动添加的配置；手工配置的 Studio 工作流仍按原有方式管理。

资源助手用于查找和打开资源：项目会话可以使用当前项目中已接入资源目录的内容类型；群聊只查找本群已经接受且仍有效的共享引用。它本身不授予内容读取、编辑或数据分析权限。

### 对话示例

- **打开**：“请在工作台打开‘库存透视｜工厂数量与价值’，只展示。”
- **查询已有数据集**：“请查询共享看板中已授权的库存数据集，说明结果的范围。”
- **进一步分析**：“请按工厂汇总库存价值，列出最高的五项，并说明是否覆盖完整数据。”

匹配唯一资源时，Agent 可以请求在提问者当前工作台打开，并提供可点击的资源条目；存在多个匹配项时，需要进一步指定名称或点击选择。其他成员的工作台不会被一起打开，加载历史消息或重连也不会重复自动打开；仍可点击历史条目重新校验权限后查看。

数据分析需要**源方授权、群主接受分析权限、提问成员具备数据源权限**同时成立。群主身份或“资源助手”能力都不能替代这些条件。已加入群聊的 Assistant 在成员发起的有效群聊执行中使用受控分析工具，不需要读取源草稿或切换到源项目。

## 权限与有效范围

| 角色或范围   | 权限边界                                                      |
| ------------ | ------------------------------------------------------------- |
| 源项目管理者 | 可发起和撤销查看授权；分享分析能力还须满足数据来源的额外要求  |
| 群主         | 可接受授权和移除引用；不能扩大源方的分析范围                  |
| 群成员       | 可打开有效引用；人工查询和发起 Agent 查询均使用自己的数据权限 |
| 群内 Agent   | 代表发起成员在已接受的范围内执行；不借用创作者身份或凭据      |
| 其他群聊     | 即使绑定同一个项目，也不能使用本群的授权，须另行授权并接受    |

当前 Data Xpert 数据来源要求分享者具备其数据管理员权限，并且相应只读操作可用；项目文件数据集要求分享者能管理对应项目文件。执行查询时仍检查提问成员的数据访问权限，文件数据集也不例外。不支持分析授权的数据来源不能用项目管理权限绕过。

**Agent 查询结果可能发布给群内所有成员。** 群主接受分析权限时需要确认这一受众范围；它不是每个收件人分别重新查询的私有报告。平台记录授权与查询操作的审计信息，但不把结果单元格写入分析审计记录。

## 版本、撤销和更新

- **固定正式版本**：引用固定看板定义和数据绑定版本；源方发布新版本不会自动更新群内引用。数据仍按访问时的权限查询，因此固定看板版本不代表冻结业务数据。
- **更换版本或权限**：撤销旧授权，重新选择版本和分析范围，再由群主接受。
- **源方撤销**：在源看板的群聊授权列表点击**撤销授权**。
- **群主移除**：在共享资源中点击**移除引用**。源看板保持不变，再次添加需要重新授权。
- **访问失效**：到期、成员退出或被移除、群聊更换绑定项目、相关资源提供方不可用，都会使对应访问无法继续。旧项目上的引用不会自动迁移到新项目。

后续打开、读取和查询会重新检查授权；已打开的空闲查看页也会定期检查，间隔约 60 秒。查询进行中发生撤销时，服务端会在返回数据及发送分析回答前再次检查。撤销不能收回已经发送的聊天内容、已看到或保存的数据，也不能清除已进入模型上下文或外部模型服务的信息。

## 当前分析限制

| 限制         | 当前行为                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------ |
| 分析范围     | 仅所选正式版本声明并已授权的数据集、字段及固定行范围                                             |
| 查询方式     | 不开放任意 SQL、其他表或模型查询、写入、导出或无人触发的定时探索                                 |
| 单次群聊执行 | 最多 8 次查询尝试，跨共享资源合计                                                                |
| 单次查询     | 30 秒期限，来源扫描最多 1,000 行；结果最多 100 行且受 64 KB 大小限制，还须遵守更小的授权行数上限 |
| 汇总完整性   | 上游结果不完整或被截断时，拒绝将其聚合结果作为完整汇总返回；可以缩小合法查询范围后重试           |

## 常见问题

| 现象                             | 检查方法                                                                             |
| -------------------------------- | ------------------------------------------------------------------------------------ |
| 提示“无法管理授权”               | 回到已正常登录的源创作会话，确认源项目管理权限；确认宿主支持授权管理入口             |
| 没有可选群聊                     | 确认自己已加入目标群聊、群聊已绑定项目；刷新或加载更多                               |
| 数据集不可勾选或分析选项加载失败 | 检查所选正式版本的数据集声明、数据来源支持和分享者的数据授权资格                     |
| “授权给群聊”不可点击             | 检查版本、群聊及分析范围是否完整；同一目标存在有效待接受或已生效授权时，先撤销旧授权 |
| Agent 能打开看板，却不能分析     | 检查源方是否提供分析权限、群主是否勾选接受，以及提问者是否有数据源权限               |
| Agent 找不到看板                 | 检查资源助手已启用并发布、Assistant 仍在群内、引用已接受且未失效；使用完整标题       |
| 提示版本或访问权限变化           | 重新打开检查；若授权到期、撤销或群聊更换项目，需重新授权并接受                       |

## 平台与插件的职责

| 部分                        | 负责的功能                                                                     |
| --------------------------- | ------------------------------------------------------------------------------ |
| Xpert 平台（OS / Pro 共用） | 授权、群主接受、固定版本引用、成员与项目检查、分析范围和查询预算、审计         |
| Live Dashboard              | 看板发布、数据集与控件语义、源分享表单、看板画布及创作工具栏                   |
| ChatKit / Cloud / Bosi      | 通用共享资源菜单、权限范围展示、工作台标签页，以及已登录创作会话的授权管理连接 |

群聊共享机制通过资源类型扩展接入具体业务，不要求 ChatKit 为 Live Dashboard 编写独立的授权流程。本文用看板说明操作；其他资源类型须先支持相应的只读展示和分析能力，才能提供同等功能。
