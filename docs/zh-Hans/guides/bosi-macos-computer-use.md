[English](/en/guides/bosi-macos-computer-use)

在 macOS 14 及以上版本，启用了**本机窗口操作**的助手可以读取你为本次任务选定的应用窗口，在其中输入文字、点击按钮或滚动内容。本机窗口操作、云电脑和本机 Shell 可以分别启用。

灵动岛会显示助手正在操作的窗口。你可以直接停止操作，键盘焦点仍留在前台应用。见[macOS 灵动岛](/zh-Hans/guides/bosi-macos-island)。

## 设置和使用窗口操作

1. 首次启动时先选择语言，Bosi 会使用所选语言打开**本机窗口操作**页面。点击**打开系统设置**，授予**屏幕录制**和**辅助功能**权限，返回 Bosi 后点击**重新检查权限**。若 macOS 提示重新打开应用，请重新启动 Bosi。也可选择**稍后设置**，之后从**设置 → Computer Use**进入。
2. 创建个人 Bosi 或空白助手时，选择**本机窗口操作**，并选用支持视觉和工具调用的模型。要给已有助手添加此能力，请在 Studio 中为主智能体添加 `DesktopComputerUse` 中间件，启用 `desktop_window_control` 并发布助手。
3. 在 Mac 上打开与该助手的单聊。例如，在「文本编辑」中新建空白文稿，让助手在你指定的窗口中输入两行中文，读回并核对标点和换行。
4. Bosi 打开原生窗口选择器，显示助手名称、本次任务及可选窗口。选定窗口后，它的截图和辅助功能控件信息会通过 Xpert 提供给助手的模型。点击**取消**可拒绝本次任务。
5. 操作期间，对话中显示助手名称和目标窗口标题。点击**停止操作**会立即收回本次窗口授权；助手也可在任务完成时主动释放窗口。若要查看或撤销 macOS 系统权限，打开**设置 → Computer Use**，点击对应权限旁的**管理**。返回 Bosi 后，页面会刷新权限状态。

## 支持的操作

| 工具动作           | 功能                                                                                                        |
| ------------------ | ----------------------------------------------------------------------------------------------------------- |
| `start`、`observe` | 返回所选窗口的截图、辅助功能控件的角色、标签和值，以及本次快照 ID。候选窗口的标题列表只在本机选择器中显示。 |
| `type`             | 在原生文本框或文本区域的当前插入点输入 Unicode 文本。已有选区时替换所选内容。                               |
| `click`、`scroll`  | 触发辅助功能控件的按下动作，或通过垂直滚动条向上、向下滚动。                                                |
| `finish`           | 释放原生驱动和本次任务的窗口授权。下一次任务需要重新选择窗口。                                              |

目标窗口必须可见，并且能在所属进程中唯一匹配到一个辅助功能窗口。窗口关闭、匹配出现歧义、出现模态对话框或缺少所需权限时，Bosi 会阻止后续操作。辅助功能控件列表会排除密码字段，但截图可能包含所选窗口内的所有可见内容。需要按像素坐标输入的画布和游戏不在支持范围内。

Bosi 同时只允许一个窗口任务，最长运行 5 分钟，最多调用工具 40 次。每项授权绑定服务地址、租户、用户、组织、助手、对话线程、本次运行和所选窗口。每次输入都需要使用最新快照中的控件 ID，并会消耗该快照；下次输入前，助手需要重新观察窗口。同一次工具调用的重复回调复用已记录的结果。停止任务、切换对话、退出账号、退出 Bosi、锁屏或让 Mac 睡眠，都会释放授权。

## 实现

- `desktop-computer-use` 能力提供方声明模型要求，并将 `DesktopComputerUse` 挂载到主智能体。服务端通过 ChatKit 请求客户端调用工具，收到结果后继续运行。每次观察生成一条包含文字和图像的工具消息，供模型读取。[能力提供方](https://github.com/xpert-ai/xpert/blob/develop/packages/server-ai/src/xpert-template/capabilities/builtin-capabilities.ts) · [助手中间件](https://github.com/xpert-ai/xpert/blob/develop/packages/server-ai/src/xpert-middleware/desktop-computer.middleware.ts)
- 对话在转发请求前校验当前助手、线程和工具调用 ID。Electron 主进程管理原生窗口选择器、窗口授权、重复请求记录以及驱动的生命周期。[对话接入](https://github.com/xpert-ai/xpert/blob/develop/apps/desktop/src/ChatPanel.tsx) · [窗口控制器](https://github.com/xpert-ai/xpert/blob/develop/apps/desktop/electron/computer-use/controller.cjs)
- 主进程通过专用标准输入、输出管道与随应用分发的 Swift 辅助进程通信。ScreenCaptureKit 捕获所选窗口；辅助功能操作只针对该 AX 窗口对象内的控件，文字直接写入应用的文本控件。[Swift 驱动](https://github.com/xpert-ai/xpert/blob/develop/apps/desktop/native/computer-use/WindowControl.swift) · [Apple ScreenCaptureKit](https://developer.apple.com/documentation/screencapturekit) · [Apple AXUIElement](https://developer.apple.com/documentation/applicationservices/axuielement)
- Bosi 在语言选择后记录待完成的权限步骤，重启后可以接着设置。已有安装可从设置页进入。**重新检查权限**会读取当前状态；点击**打开系统设置**才会进入 macOS 授权流程。[权限页面](https://github.com/xpert-ai/xpert/blob/develop/apps/desktop/src/computer-use/ComputerPermissions.tsx) · [OpenBot 0.69.0 的宿主与驱动架构](https://github.com/nightly-labs/openbot/blob/v0.69.0/docs/architecture/computer-use.md)

## Mac 真机验收

2026 年 11 月 14 日，团队在运行 macOS 26.5.1 的 Apple 芯片 Mac 上验证了 Bosi Electron 开发版。测试使用本地 Xpert API、独立的桌面用户配置和单独发布的测试助手。开发宿主此前已获得两项系统权限。全新系统上签名发行版的首次授权弹窗，以及 Intel 芯片 Mac 的真机运行，仍待发布验收。

| 检查项           | 观察结果                                                                                                                                           |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 首次启动         | 新用户配置依次显示语言选择、窗口权限和登录页面。权限页面正确显示两项原生权限均已授予。                                                             |
| 模型工具调用     | 已发布的助手依次调用 `start`、`type`、`observe`、`finish`，在所选窗口的辅助功能文本区域中输入两行中文，再通过新快照核对全文。                      |
| 桌面对话         | 另一项任务经过桌面 ChatKit 客户端工具处理器、原生选择器和本地驱动。测试程序在 Bosi 自己的窗口选择器中选定目标。                                    |
| 文本与窗口范围   | 通过「文本编辑」的文稿接口独立读回内容，逐字匹配预期文本，包括标点、换行和最后一个字符。另一个已打开的文稿保留原始内容。                           |
| 拒绝、撤销与重放 | 真机驱动拒绝了过时快照，也拒绝了任务结束后的请求。控制器回归测试覆盖取消窗口选择、停止后重放、重复调用，以及来自其他组织、对话、助手或运行的请求。 |

下列 JSON 验收样例使用 Unicode 转义保存原始文件名和中文。请先解析 JSON，再将解码后的文本交给助手。预期文本只有一个换行符，最后的句号之后没有换行。

```json
{
  "target": "Bosi-\u7a97\u53e3\u9a8c\u6536-1114.txt",
  "expectedText": "\u4f60\u597d\uff0cBosi\u3002\n\u8fd9\u662f\u6307\u5b9a\u7a97\u53e3\u7684\u4e2d\u6587\u9a8c\u6536\u3002"
}
```

复验时，在「文本编辑」中打开两个名称不同的纯文本文稿。目标文稿留空，记录对照文稿的初始内容。请助手在目标文稿中输入解码后的文本，读回核对并结束任务。再通过「文本编辑」独立读取两个文稿，将目标文稿与 `expectedText` 逐字比较，并确认对照文稿的内容如初。任务结束后，对话中的**停止操作**按钮应消失。

## 原始实施计划与验收标准

原计划位于 `docs/plans/bosi-macos-computer-use.md`，真机测试完成后转入本功能文档。

| 阶段            | 实现                                                                                                                                                | 验收标准                                                                                                       |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 1. 助手能力     | 注册可选的 `desktop-computer-use` 能力，在 Bosi 初始化时提供选项，在 Studio 中接入中间件。复用模板能力注册、模型筛选和 ChatKit 客户端工具中断机制。 | 仅启用该能力的助手会向模型提供此工具。服务端沙箱、本机 Shell 和窗口操作可独立选择。                            |
| 2. 首次启动     | 语言选择后展示两项系统权限的状态，提供系统设置、重新检查和稍后设置入口。已有安装可从设置页进入。                                                    | 中途退出后可从待完成的步骤继续；完成或跳过后，下次启动直接进入后续页面。每次任务仍需单独选择窗口。             |
| 3. 原生执行     | Electron 持有授权，转发当前助手、线程及运行的工具请求。提供目标窗口的截图和辅助功能控件，每次输入引用当前观察中的控件。                             | 缺少权限、窗口匹配有歧义、窗口消失、快照过时或控件不支持该操作时，拒绝输入。                                   |
| 4. 会话生命周期 | 一次运行绑定一个窗口，按顺序执行操作，处理重复请求并提供停止入口。                                                                                  | 过时快照和重复提交都不会造成二次输入。范围变化、授权撤销、应用退出或超时会终止访问，其他助手须取得自己的授权。 |
| 5. 端到端验收   | 使用独立用户配置、中文测试文本、空白的「文本编辑」目标文稿和单独的对照文稿。                                                                        | 记录构建版本、权限状态、助手的实际工具调用、原生写入、独立读回、重放处理和授权撤销结果，并单列待发布检查项。   |
