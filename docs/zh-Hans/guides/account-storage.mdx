账号存储空间用于保存受管应用的文件和应用记录。用户可以查看已用空间、剩余空间及容量上限；管理员可以通过会员套餐为账号提供更大的容量。

本功能适用于通过 App Platform 交付的[受管应用](/zh-Hans/guides/managed-apps)账号。同一租户内，同一账号的受管应用共享存储容量。容量调整不会改变文件、项目或共享资源的访问权限。

## 查看存储用量

在 Web 中打开**设置 → 账号 → 使用情况和计费**（`/settings/account/billing`），进入**套餐与余额**页签，查看**存储空间**。

页面提供以下信息：

- 已使用的空间、当前容量上限、剩余空间和使用比例。
- **文件**与**应用记录**各自的占用量。
- 最近一次统计的时间，以及等待统计、统计延迟或读取失败的提示。

用量是定期统计的近似值。上传或删除后，先等待统计更新，再点击**刷新用量**读取最新结果；刷新按钮不会立即重新扫描全部文件。尚未完成首次统计时，用量未知，不代表占用为零。容量上限则按当前有效权益计算。

如果看不到存储空间，确认账号已交付受管应用，并具有账号计费页面和应用使用权限。普通非受管账号不一定显示此项。权限说明见[角色与权限](/zh-Hans/guides/role-permissions)。

## 存储容量如何计算

每个受管应用账号有基础容量。有效会员套餐可以提高账号的总容量，但不会降低基础容量。如果同一账号关联多个应用基础容量配置，基础容量采用其中较小的上限；多个有效会员容量取最大值，不相加。

| 情况                                                        | 账号容量 |
| ----------------------------------------------------------- | -------- |
| 基础容量为 2 GiB，套餐未设置存储容量                        | 2 GiB    |
| 基础容量为 2 GiB，当前有效套餐容量为 20 GiB                 | 20 GiB   |
| 基础容量为 2 GiB，同时具有适用的 20 GiB 和 50 GiB 会员容量  | 50 GiB   |
| 基础容量为 2 GiB，20 GiB 会员容量到期且没有其他有效容量权益 | 2 GiB    |

以上数值仅为示例，实际容量以账号页面为准。1 GiB = 1,024 MiB。套餐容量是可占用空间的总上限，不是每月增加的空间；续期相同套餐不会让容量逐月累加。

## 管理员配置套餐容量

具有会员管理权限的管理员可以在**设置 → 会员**（`/settings/membership`）中管理套餐和用户会员。

1. 确认当前租户或组织范围与目标应用账号一致。
2. 在**套餐配置**中新建或编辑套餐。
3. 填写**套餐存储容量（GiB）**，使用正整数，例如 `20`。留空表示不提供额外会员容量，账号仍按基础容量及其他有效权益计算；留空不表示无限容量。
4. 保存套餐，再通过**用户会员管理**为目标账号分配适用套餐，核对生效周期和状态。
5. 在目标账号的存储空间页面确认当前容量。

已生成的会员周期保留该周期确定的容量权益。编辑套餐目录不会追溯修改这些周期，也不会仅因管理员填写了新容量就立即为现有会员扩容。需要调整现有账号时，通过会员管理确认套餐分配和实际生效周期。

历史会员周期如果没有记录存储容量，仍使用基础容量；旧分配记录完全没有周期权益快照时，可以沿用其关联套餐的配置。

## 容量不足与套餐到期

套餐容量仅在会员和周期有效期间提供。未来周期尚未开始，或相关会员已暂停、过期，或周期已取消、进入退款处理时，不提供该周期的额外容量。其他有效权益仍按上述规则计算。

容量缩小后，已用空间可能超过新上限。系统保留已有文件，不会因到期或超额自动删除它们。

| 操作                                 | 容量不足时的行为                     |
| ------------------------------------ | ------------------------------------ |
| 读取、下载已有文件                   | 仍可按原有访问权限操作               |
| 删除不再需要的文件                   | 可以操作，释放的空间在统计更新后反映 |
| 用不增加占用的文件替换原文件         | 可以操作，仍需满足其他文件规则       |
| 新增上传、保存生成文件或其他增长写入 | 超过容量上限时拒绝写入               |
| 启动新的 Agent 任务                  | 达到容量上限时阻止启动               |

容量上限和模型点数分别管理。增加点数不会自动增加存储空间；增加存储空间也不会增加点数。单次上传大小、临时目录、项目数量和并发任务等限制仍独立生效。

## 恢复因容量不足停止的任务

Agent 工具明确报告账号存储容量不足时，本次运行会结束并保留执行记录及已有检查点，避免模型反复修改参数重试同一问题。已经保存的成果仍然保留。

1. 删除不再需要的文件，或联系管理员调整有效套餐容量。
2. 等待用量更新，确认剩余空间足以容纳本次任务的新成果。
3. 回到原工作台，使用该任务提供的重试或恢复入口继续操作。

恢复容量不会自动重启任务。能否从中断处继续取决于该工作台和任务的恢复能力；用户重新发起的模型调用按现有点数规则计费。如果仍提示容量不足，检查统计时间；统计长时间未更新或读取失败时，请联系管理员处理。

## 版本与购买方式

存储用量展示、套餐容量配置、到期后保留文件，以及容量不足时停止 Agent 重试，均属于 Xpert 通用功能。管理员可以直接分配套餐，无需接入支付服务。

在线购买和支付由 Xpert Pro 扩展提供。用户能否看到购买入口，取决于部署是否启用购买功能、可售商品和支付配置。需要扩容时，应确认所选套餐包含所需的存储容量；单独购买点数不会扩容。未提供购买入口时，请联系管理员分配适用套餐。
