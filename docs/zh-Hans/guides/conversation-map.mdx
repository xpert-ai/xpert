title: '对话脉络'
description: '浏览项目对话和讨论分支，搜索历史消息，并从脉络图、列表或生长树定位原始问答。'
---

对话脉络是 Assistant 工作台中的内置视图，用于浏览已有对话、理解讨论分支的来源、搜索历史问答，以及返回原对话继续交流。它提供**脉络图、列表、生长树**三种展示形式。

## 打开与选择范围

从 Assistant 的工作台菜单打开**对话脉络**，视图会显示在独立页签中，无需配置额外中间件。视图按需打开，首次进入聊天时不会自动展开。

没有已保存偏好时，视图使用当前项目，默认打开**脉络图 → 分支脉络**，采用纵向、紧凑节点，隐藏历史版本和共享历史。项目选择器只提供当前 Assistant 版本族下有权访问的项目；选择**未归入项目**可浏览没有项目归属的对话。

顶部 Header 放置视图切换、项目选择和对话或消息搜索；下一行工具栏显示当前视图的功能：

| 视图   | 内容工具栏                                                  |
| ------ | ----------------------------------------------------------- |
| 脉络图 | 分支脉络 / 会话关系、方向、显示样式、历史版本与共享历史设置 |
| 列表   | 历史版本与共享历史设置                                      |
| 生长树 | 对话与分支选择、返回讨论脉络、历史版本、活动记录、刷新      |

新建对话使用宿主聊天入口。对话脉络中的操作围绕已有对话及其分支展开。

## 三种展示形式

### 群聊公开讨论

在群聊中打开对话脉络，会自动显示当前群的公开消息，包含所有成员的发言，而不局限于主 Assistant。群聊范围固定为当前群；同项目的其他群和 Assistant 内部执行会话不会混入。

- **脉络图**通过连接线展示请求、回复和接续关系；**列表**按消息顺序浏览；**生长树**把交错进行的讨论按真实父消息关系归在一起。
- 可按发言成员筛选和搜索消息，支持加载更早的记录。筛选隐藏了父消息时，会提示“关联消息在当前范围之外”。
- 消息区分普通发言、请求、中间答复、最终答复，并标识资源卡片和分析结果。脉络展示摘要；点击节点后选择**在群聊中定位**可查看原文和卡片，**查看关联消息**可返回对应问题。
- 群成员身份只授权读取公开讨论。内部工具调用、提示词与执行过程仍通过已有的**助手处理记录**入口单独鉴权；群聊脉络不提供单聊的分叉、重命名等操作。

下文的项目选择、分支和历史版本操作适用于单聊。

| 形式   | 适合查看                                          | 展示方式                                       |
| ------ | ------------------------------------------------- | ---------------------------------------------- |
| 脉络图 | 讨论路径和对话之间的来源关系                      | 卡片与连接线，可切换分支脉络和会话关系两个视角 |
| 列表   | 标题、最近问题、更新时间和快捷操作                | 带缩进、展开箭头和引导线的目录列表             |
| 生长树 | 讨论如何分叉，以及一条回复由哪些 Agent 和活动形成 | 从根部向末端收细的枝条、活动叶片和浮动详情面板 |

### 脉络图的两个视角

**分支脉络**沿真实消息祖先关系组织讨论，将共同消息前缀压缩成共享片段，在路径实际分离的位置分叉，适合追踪同一段讨论如何发展出不同方向。

**会话关系**展示对话、分支和问答节点，保留分支父子关系，并用虚线标明独立对话的来源，适合查找某个对话、分支或问答与其他记录的关系。

两个视角位于同一个脉络图页签中。切换到列表或生长树后再返回，会保留此前选择的视角；宿主刷新后也可恢复。已有 `mode=tree` 和 `mode=graph` 链接分别进入对应视角。

脉络图支持横向或纵向排列、放大缩小、适配画布和小地图。卡片底边中央的按钮用于展开或折叠。连接线展示已经存在的关系，拖动连接线不会修改对话关系。

**显示**菜单提供紧凑和摘要两种节点样式。紧凑样式突出标题和短摘要；摘要样式展示更多问题内容和对话上下文。卡片随内容调整大小，悬停可查看完整标题和时间。

### 列表与生长树

列表第一行展示类型图标、标题、更新时间和快捷操作，第二行展示问题或回复摘要。展开箭头与标题选择分别操作；标题获得键盘焦点后，可以使用左右方向键折叠或展开。

生长树分为**讨论脉络**和**本轮执行**两层，具体语义与操作见[生长树功能指南](/zh-Hans/guides/conversation-trail)。

## 项目和对话选择器

项目选择器和生长树中的对话选择器采用可搜索的组合选择控件。搜索由服务器在有权访问的范围内执行，能够查找尚未加载到下拉列表中的记录。

- 滚动接近列表底部时自动追加下一页，每页 20 项。
- 视图存续期间，已加载页和滚动位置按范围、搜索词缓存。关闭再打开浮层，或切换视图页签，不会从第一页重新加载。
- 清空搜索会恢复已缓存的未筛选列表；刷新、数据修改和宿主上下文变化会使缓存失效。
- 列表提供加载中、无匹配结果、失败重试及键盘选择状态。
- 切换项目会清理原有对话、分支和回复定位，避免继续显示上一个项目的执行树。

**对话选择器搜索标题；Header 中的搜索同时查找对话标题和用户可见消息内容。**

## 节点与关系

| 节点 | 含义                     | 主要信息                                             |
| ---- | ------------------------ | ---------------------------------------------------- |
| 项目 | 对话所属的项目范围       | 项目名称和更新时间                                   |
| 对话 | 一次独立对话             | 标题、当前分支的最近用户问题和更新时间               |
| 分支 | 对话内部的一条讨论路径   | 分支名称、所属对话、最近问题、更新时间和当前分支标记 |
| 问答 | 用户问题及其后续可见回复 | 问题摘要、所属对话和更新时间；选择后可预览问答       |

分支可以继承祖先路径上的消息。继承的问题显示相应标记，开启**显示共享历史**可查看这部分内容；开启**显示历史版本**可包含编辑消息产生的旧讨论版本。

独立分叉创建新的对话，来源连接只表示出处，不改变新对话的归属。分支脉络在来源片段已加载且可访问时，将独立副本连接到准确的来源片段；会话关系用虚线表示来源。

对话和分支可以重命名。问答节点标题直接摘取用户问题；缺少问题文本时显示占位内容，不调用模型补写标题。缺失的更新时间不会被推测填充。

## 搜索与原消息定位

Header 搜索限定在所选项目和当前 Assistant 版本族中有权访问的对话，匹配标题、用户问题和可见回复的文本片段。结果高亮匹配内容，并展示项目、对话、分支和消息的位置路径。

同一对话中由多个分支共享的消息只显示一条搜索结果，可以在结果中选择要打开的分支。**显示历史版本**决定旧版本是否参与搜索；使用**继续搜索更多对话**继续获取结果。

选择**在聊天中定位**后，宿主打开对应对话和准确分支，必要时加载更早的历史，然后滚动到目标消息并高亮。在最大化工作台中定位时，会先显示聊天区；窄屏会关闭遮挡聊天的工作台面板。目标不存在、无权访问或无法读取时，界面会提示失败。

## 对话操作

| 操作         | 入口                         | 结果                                                                   |
| ------------ | ---------------------------- | ---------------------------------------------------------------------- |
| 在聊天中定位 | 卡片、列表快捷操作或问答预览 | 打开对话和分支；指定消息时滚动并高亮                                   |
| 开启旁聊     | 分支快捷操作或菜单           | 从该分支最近一条已封存回复创建同一对话内的新分支                       |
| 分叉到新对话 | 支持分叉的回复操作           | 从回复的保存状态创建独立对话，并复制截至该回复的历史；项目文件继续共享 |
| 重命名       | 对话或分支菜单               | 更新对话标题或分支名称                                                 |
| 复制链接     | 操作菜单                     | 复制包含对话、分支及可选消息位置的链接，保留当前视图和显示参数         |

旁支讨论可从运行中或暂停中的分支发起，源分支保留原执行状态。没有已封存回复时，界面会说明原因。独立分叉需要完整回复和可用的保存状态；不支持的状态格式、缺失状态或未完成回复会阻止分叉。

操作等待完成时会阻止重复触发；创建和分叉的重试复用原请求标识。打开或定位对话会保留对话脉络页签、查询和布局；浏览与导航不会发送消息或停止正在运行的分支。

## 权限、状态与使用边界

- 项目、对话、数量统计、搜索和操作均遵循组织与资源权限。读取、参与和管理使用各自权限，重命名需要管理权限；复制链接不会授予访问权限。
- 消息浏览只展示用户可见内容，排除内部运行时输入、私有工具输入、推理内容和检查点。生长树中可查看的公开工具记录遵循独立授权与脱敏规则。
- 宿主保存项目、搜索和显示偏好，并恢复生长树的对话、分支与回复位置。上下文变化后重新读取授权数据，过期请求的结果不会覆盖新状态。
- 界面跟随宿主语言、浅色或深色主题与圆角配置。页签、菜单、搜索结果、列表和问答预览支持键盘操作，窄屏调整次要控件的布局。
- 搜索分页扫描可见历史，记录较多的对话可能需要更长时间。消息定位需要宿主 ChatKit 支持对应能力；不支持时显示明确提示。

## 相关功能

- [生长树](/zh-Hans/guides/conversation-trail)：主干、叶片与分叉语义、活动记录、缩放定位和数据边界。
- [群聊](/zh-Hans/guides/group-chat)：多人和多个 Assistant 的共享对话。

### 单聊与群聊共用的视图

两种对话使用相同的脉络图、列表、生长树、搜索和消息详情。群聊额外提供成员筛选；只显示当前群聊范围，不提供单聊的分支编辑、旁聊或私有执行记录入口。

平台将授权后的数据适配为统一的脉络读模型：`scope` 表达可见范围，`nodes` 表达会话和消息，`edges` 区分包含、分支、回复和因果关系，`capabilities` 提供可用操作，`pageInfo` 提供分页信息。三种展示方式使用同一份数据；不会因切换视图而改变权限。请求、进度答复、最终答复是消息属性，时间先后本身不表示回复或因果关系。

筛选或分页后，关联的父消息可能尚未加载。当前消息仍会显示；加载到父消息后，会恢复关联关系。看板和结果卡片只显示公开消息中的摘要和标记，完整内容通过“在聊天中定位”查看。

单聊中的执行详情仍使用专门的执行轨迹模型，按独立权限加载；统一脉络读模型不会把工具调用或私有运行记录转换成群聊公开消息。
