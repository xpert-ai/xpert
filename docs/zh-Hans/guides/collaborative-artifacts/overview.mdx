协作成果把白板讨论、表格整理、数据分析和内容交付连接起来。团队与 Assistant 操作同一份有身份、权限和版本的资源；转换后的成果保留来源，并通过显式更新保留人工修改。

## 从哪里开始

在绑定了项目的 Assistant 中打开 Spaces 或对应应用视图，也可以从聊天中的资源卡片进入工作台。项目、资源和版本共同确定打开目标；同名标题不能用于辨认资源。

| 需要完成的工作         | 使用入口                  | 保存的结果                         |
| ---------------------- | ------------------------- | ---------------------------------- |
| 梳理问题、流程与行动项 | Canvas 白板               | 可共同编辑的画布                   |
| 整理行动项、预算与计算 | Office Editor 原生 Sheets | 有操作历史的工作簿                 |
| 查询数据并发布图表     | Live Dashboard            | 草稿及不可变正式版本               |
| 固定分析结论及其依据   | 分析证据视图              | 带来源、参数、时间和摘要的数据快照 |
| 交付报告、幻灯片和视频 | Office Editor、Motion     | 从指定证据生成的新成果             |

管理员需安装对应插件、为 Assistant 配置所需能力，并授予项目及数据访问权限。视图可见不代表 Agent 已配置编辑工具，也不代表用户具有来源数据权限。Cloud 与嵌入 ChatKit 的宿主可以打开同一服务端资源；浏览器本地草稿仍按宿主来源分别保存。

## 白板共同编辑

Canvas 使用 Yjs 同步画布。schema v2 将记录中的属性、数组和受支持文本映射为共享结构，使不同成员与 Agent 可以分别修改同一对象的不同部分。已有 schema v1 文档需要显式升级；升级保留资源身份和内容，并终止旧会话，旧客户端不能继续写入新格式。

- 编辑器提交相对于已知基准的变化，保留其他成员的独立修改。
- 不兼容的文本、数组基准或过期 Agent 操作会返回冲突；使用 Yjs 不意味着所有富文本竞争都能无损合并。
- 重连从持久协作状态同步。项目撤权后停止后续同步和读写，不能凭旧会话继续访问。
- Agent 与人工编辑遵守同一资源范围、版本和权限约束。已有内容发生变化时，应重新读取后形成新的修改意图。

项目画布使用项目授权；没有项目归属的旧个人画布保留创建者范围，组织相同不会自动开放协作。

## 将白板内容转为成果

1. 在白板中确定需要整理的内容，选择转换为工作簿或文档。
2. 转换读取当前获授权的来源版本，创建新的原生目标，保留来源资源、版本及元素引用。
3. 在目标编辑器中继续整理和保存；之后的人工修改属于目标自己的版本历史。
4. 来源变化后，显式创建更新副本，再决定采用哪些变化。

同一转换请求重试会返回已有目标；来源版本过期则拒绝转换。转换不会建立双向实时同步，也不会用新的白板内容覆盖已编辑的目标。白板文本进入工作簿时不作为可执行公式注入。

## 与 Assistant 协作

在支持的编辑器中选择对象或单元格，再使用“引用选区”把当前上下文交给 Assistant。上下文包含资源、视图实例、版本与未保存状态；它用于定位任务，实际读写仍由服务端授权。

切换资源或关闭视图会清理该视图的上下文。Assistant 应根据返回的保存回执说明结果，不能把工具已发起、文件已生成或回复中的文字当成资源已保存。

如果交互式 MCP App 提供当前视图工具，可为 Assistant 配置 [MCP App 视图工具](/zh-Hans/guides/mcp-app-tools)。调用绑定当前聊天中的确切实例并经过确认；该能力与 Canvas、Sheets 的持久写入协议分别管理。

## 保存、发布与来源

| 行为                     | 用户可依赖的结果                                             |
| ------------------------ | ------------------------------------------------------------ |
| 保存工作簿或文档         | 使用各编辑器的提交协议保存内容，并返回对应版本或修订         |
| 保存看板草稿             | 不改变当前正式版本和既有分享目标                             |
| 发布看板                 | 经人工确认产生新的不可变正式版本                             |
| 将看板历史版本恢复为草稿 | 保留正式版本，重新审核后才能发布                             |
| 从分析证据生成成果       | 固定使用选定快照，保留数据引用；刷新来源不会静默改写已有成果 |

来源追溯和访问授权持续有效：证据派生的报告、幻灯片及视频会在受管访问时重新核验来源。移除正文中的来源标记不能解除检查。已经下载到用户设备的文件无法远程收回。
