可信数据把指标定义、查询结果和下游成果连接起来。认证说明业务口径经过授权确认；查询回执记录实际执行；证据快照保留某次结果。这三者分别管理，不能用查询成功或页面显示正常代替业务认证。

## 指标认证与失效

在 Data Xpert 指标管理中，由具有认证权限的用户通过专用操作认证指标。普通创建或编辑不能直接授予认证。

认证绑定规范化定义摘要、模型及发布版本、认证人和时间。工作空间、模型、业务作用域、计算定义等影响口径的变化使当前认证失效；仅修改展示名称或调整 JSON 对象键顺序不会误撤销认证。改回旧定义仍需重新认证。

| 状态             | 含义与处理                                                                   |
| ---------------- | ---------------------------------------------------------------------------- |
| 已核验认证       | 来源为本次查询核验了定义和依赖版本；不承诺未来永久有效                       |
| 历史未核验       | 旧认证缺少版本绑定证明，标为 `legacy_unverified`；重新认证后才能提供当前证明 |
| 模型或定义变化   | 旧证明不能继续用于新查询，更新口径并重新认证                                 |
| 无法核验或无权限 | 不释放未经核验的受管结果，恢复有效来源或权限后重试                           |

认证、撤销和定义失效等事件追加到历史，普通展示编辑不制造新的认证事件。认证历史按当前资源权限读取；过去的一次批准不代表当前仍有效。

## 在看板中阅读来源

看板的 Sources 与分析证据保留来源版本、查询时间、字段单位、完整性以及来源提供的认证证明。`decimal` 和 `int64` 使用精确字符串运输，避免大数和小数被浮点舍入。

阅读结果时分别判断：

- **口径**：来源是否提供当前可核验的业务认证。普通 SQL、临时计算或度量覆盖不会自动继承指标认证。
- **执行**：本次查询是否成功，结果是否完整。截断、分页或抽样结果不能冒充完整总额。
- **新鲜度**：实际查询和来源取数时间是什么；页面刷新时间不是业务数据更新时间。

来源在查询前后核验授权、版本和认证。执行中发生撤权或口径变化时，旧结果不能在完成后继续交付。

## 刷新与结果复用

标准看板支持可见页面的 30/60 秒刷新，用户也可手动强制刷新。这是页面运行期间的刷新机制，不是关闭页面后继续运行的后台任务。

结果复用默认关闭，按查询策略最多保留 60 秒。只有 Provider 能独立复查当前访问权和来源版本时才允许复用；每次命中仍重新授权。缓存按身份、查询、参数及来源版本隔离，保留原执行时间；失败不缓存，强制刷新重新执行。

文件来源仍读取并校验当前文件，只复用允许的解析和聚合结果。Data Xpert 来源继续执行新查询，不能假定所有 Provider 都支持缓存。看板的查询和渲染协议见[数据协议与页面渲染](/zh-Hans/guides/artifacts-dashboard/data-and-rendering)。

## 向群组分享限定结果

普通分享沿用访问者自身的数据权限。另有显式的 `delegated_results` 模式，使没有底层数据源权限的群组成员可以取得授权范围内的结果，且不会获得连接凭据、源项目成员身份、编辑权或转授权。

1. 来源管理者选择固定的正式成果版本，在群组分享中启用分析并选择“委托我的权限查询限定结果”。
2. 选择允许的数据集和字段、固定行筛选、分析模式、明细权限和输出行数上限。
3. 接收群主查看范围并明确接受委托。群组内所有成员都属于该结果的受众，不仅是接受者本人。
4. 群组 Assistant 通过已接受的资源引用描述和查询数据，仅返回范围内的行列及来源证明。

默认使用发布时的参数；通过契约明确开放可变参数时，也只能使用列明的值。浏览器与 Agent 不能替换 SQL、数据源或原生查询内容。`bindings` 模式使用声明的绑定；`explore` 可在授权字段范围内进一步筛选、分组、聚合和排序，仍不能扩大固定筛选。每次结果最多 100 行，并受授权中更小的上限约束。

未明确接受委托时不会隐式启用它。平台每次恢复签发者的当前身份，并在执行前后及交付前检查授权。新正式版本不自动扩大旧授权；到期、撤销、源权限变化或接收群组绑定变化会阻断后续使用。普通组织分享链接不会自动成为委托查询链接。

## 保存和更新分析证据

在分析证据视图选择已发布的看板和参数，再选择“保存证据快照”。快照包含固定来源版本、标准化 Dataset、字段与单位、完整性、查询时间、认证快照及摘要，不携带凭据或可替换的原生查询。

事实引用精确的数据集、行和字段；推断与待核实结论单独标记。保存证据不增加数据访问权限，摘要只用于检查内容一致性。

来源更新后显式重新采集，形成新证据并展示有限差异。差异按行位置比较，最多展示 50 项，每个值最多 300 字符；行重排不能被解释为业务键匹配。新快照不会自动替换旧报告或覆盖人工修改。

## 生成报告、幻灯片和视频

从已保存证据选择“生成文档”“生成演示文稿”或“生成 Motion 草稿”。各消费者使用同一快照中的精确数值和单元格引用。重复相同请求复用目标；新证据创建新成果，已有成果保留自己的修改和历史。

证据派生文档和幻灯片的来源保护绑定不可变首快照。移除后续正文中的来源标记不能解除保护。文档、视频及证据的受管读取、转换、渲染和下载会按各自入口重新检查项目及来源访问；旧来源失效后，重新认证不会自动复活旧快照，应显式刷新并创建新成果。已下载的文件无法远程收回。

## 配音与渲染

发布的 Motion 中间件配置获授权的 TTS `narrationModel` 后，可从未编辑的证据视频草稿创建配音草稿。当前取第一条固定观测，语音输入、字幕和引用保持一致；最多 600 字符、120 秒音频，并按实际音频时长编排时间轴。

配音生成独立草稿，不修改原稿，也不声称自动朗读全部数据。生成后的 WAV 作为固定输入交给 Sandbox 渲染；重复渲染复用音频，不再次调用语音模型。模型失败或断线后可能存在不确定计费，因此不会自动重复合成。

服务端视频导出需要健康、支持执行控制的 Browser Video Runtime 与队列。编辑生成内容会使原配音/渲染摘要失效；需要新的观测时创建新的证据配音草稿。源数据刷新不会静默改写已经发布的视频。
