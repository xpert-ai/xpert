[English](/en/guides/bosi-macos-agent-dock)

智能体停靠栏（Agent Dock）在屏幕边缘显示一列对话快捷入口。点击助手头像会打开与它最近的一次单聊（如有），点击群组则会打开已有的群聊。屏幕顶部的窗口操作状态、停止按钮和待办入口见[灵动岛](/zh-Hans/guides/bosi-macos-island)。

## 使用停靠栏

1. 在 macOS 14 及以上版本登录 Bosi 并选择组织。停靠栏默认位于 Bosi 主窗口所在屏幕的右侧，最初显示最多三个助手，置顶助手优先。
2. 点击 **+** 选择快捷入口。点击助手或群组即可添加，再点一次可移除，最后点击**完成**。所选入口保存在这台 Mac 上，按当前服务器、租户、用户和组织分别记录。头像上的标记提示有未读活动或助手正在运行。
3. 拖动 **+** 下方的弧形手柄，可沿屏幕边缘上下移动停靠栏。松手后会保存它在这台显示器上的位置，下次启动 Bosi 时恢复。
4. 打开**设置 → 智能体停靠栏**，可以切换左右边缘、开启自动隐藏或关闭停靠栏。保存设置后，将指针移到屏幕边缘即可唤出已隐藏的快捷入口和手柄，移开指针则会收起。
5. 仅悬停时，当前应用保留焦点。点击快捷入口才会将 Bosi 切到前台。停靠栏和快捷入口选择器使用不会主动抢占焦点的原生面板，Mac 锁屏或睡眠时会隐藏。

## 设置

「位置」选择**在其他应用上方**，可将停靠栏放在屏幕边缘；选择**在 Bosi 窗口中**，可将它附在主窗口内。使用屏幕边缘模式时，可以让停靠栏跟随 Bosi 窗口、使用主显示器、指定某台显示器，或在所有显示器上显示。如果指定的显示器断开连接，停靠栏会暂时跟随 Bosi 窗口，重新连接后回到指定显示器。

大小滑块控制屏幕边缘停靠栏的尺寸。附在窗口内的停靠栏跟随主窗口缩放。开启自动隐藏后，还可以选择是否在边缘保留细条。选中的助手向你提问时，细条上会出现彩色波纹。开启**显示已完成的工作**后，停靠栏旁会短暂显示助手最近的回复；回复没有可用文本时会显示对话标题。点击预览可打开该线程。

行为和显示器选项通过**保存设置**生效。本页的助手开关与停靠栏的 **+** 选择器共用当前组织的快捷入口列表，在任一处增删都会立即生效。

## 原生窗口行为

主进程依据显示器的工作区域定位停靠栏，处理多屏布局和缩放变化。面板使用独立的沙箱预加载脚本和内存中的 Electron 会话。渲染进程接收显示信息和操作标识。跳转前，宿主会核对发送方、当前账号和所选入口；若选择群组，还会重新获取当前用户有权访问的群组列表。随后由 Bosi 主窗口建立常规的已认证 ChatKit 会话。

停靠栏的屏幕边缘位置、最初的三个快捷入口、上下弧形轮廓、纵向排列的头像及弹簧展开动画，参考了已安装的 Nightly Labs OpenBot 0.69.0。Bosi 在本地实现面板和导航，快捷入口在主窗口中打开对话。[OpenBot Agent Dock](https://github.com/nightly-labs/openbot/blob/v0.69.0/packages/ui/src/features/agent-dock/AgentDock.tsx) · [OpenBot 位置与偏好设置](https://github.com/nightly-labs/openbot/blob/v0.69.0/src/renderer/src/features/agent-dock/agent-dock-preference.ts)

## 验证记录

本地 Electron 开发版在运行 macOS 26.5.1 的 Apple 芯片 Mac 上使用已登录账号验证了真实助手和群聊。停靠栏从右侧切换到左侧，收起为 6 点宽的边缘细条，并响应系统鼠标事件展开。悬停时「文本编辑」保持在前台。点击助手后，Bosi 打开了它的对话；点击群组后，对应的 ChatKit 群聊打开，侧栏也选中了该群组。

另一项重启测试使用本地 API 测试数据和独立的用户配置。重启后，新进程恢复了选定的边缘、自动隐藏状态以及用户添加的第四个快捷入口。关闭停靠栏后，原生面板随即隐藏。

测试使用 Quartz 鼠标事件在左右两侧拖动手柄，将停靠栏移至工作区域顶部，并通过 **+** 打开选择器。重启后纵向位置正确恢复，从隐藏的边缘细条唤出停靠栏后仍可拖动。在 macOS 26.5.1、Electron 44.4.5 上，拖动过程中「文本编辑」保持在前台，松开手柄时 Bosi 有时会被激活。该轮桌面回归测试通过 510 项，跳过 24 项。

设置验收使用两台物理显示器和本地 API 测试数据。两台显示器上的面板按选定大小独立定位；切换到窗口内模式后，只在 Bosi 主窗口附着一个面板。设置页和快捷入口选择器同步更新，助手提问触发了边缘波纹，线程完成后短暂展示了最新回复。重启 Electron 后恢复了显示设置。该轮桌面测试通过 512 项，跳过 24 项。
