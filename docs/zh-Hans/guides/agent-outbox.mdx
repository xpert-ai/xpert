采购比价助手在后台发现交期需要核实时，会把提醒投递到采购人的通知中心。即使两次跟进都发现了同一个风险，只要针对同一报价系列和修订，采购人仍只收到一条站内提醒。新的报价修订可以产生新的提醒。

## 选择接收渠道

1. 在 Web 或 Bosi 桌面端打开**通知中心 → 通知投递设置**。
2. 选择要接收的类型，例如**采购交期提醒**或**代码评审结果**。列表取决于你在当前组织有权使用的助手和插件来源。
3. 按类型分别设置**站内通知**和**飞书私聊**。默认开启站内渠道。要启用飞书，先将本人的飞书身份绑定到平台账号，再选择当前组织中可用的机器人集成并保存。
4. 如需延后某个渠道，选择时区并填写静默开始和结束时间，例如上海时间 22:00 至次日 08:00。未设置静默时段的渠道可照常接收。

新启用的渠道从启用时起接收新发布的结果。更换机器人或重新绑定身份后，原目标的待发提醒不会转发到新账号。飞书私聊提醒显示当前可见的事项标题，详情在站内查看。需要采购人决定时，机器人会单独发送可操作的卡片。[人工决定：确认供应商延期](/zh-Hans/guides/human-decisions)

## 阅读提醒和摘要

静默结束后，系统复核每个事项。假设夜间有三条采购风险，早晨一条已经解决，你会看到另外两条组成的摘要。每份摘要最多 20 项。延长静默时段会重新合并还未开始投递的事项。

在通知中心选择提醒，可以查看获准的结果字段。代码评审提醒可包含 PR、评审状态和提交版本。只有关联会话明确且你当前有权访问时，才提供**打开会话**。某一项暂时无法核实时，其他可见提醒和公告仍可查看。打开提醒会记录这条站内通知的阅读时间，聊天中的未读消息单独计数。

如果想核对是哪次跟进触发了业务处理，可以在[事件收件箱](/zh-Hans/guides/event-inbox)查看入站事件回执。公告和个人定时任务结果的入口见[公告与通知中心](/zh-Hans/guides/notifications)。
