**状态：待实施提案。** 本文只保留原分块计划中尚未交付的能力和需重新核验的缺陷。已实现的自动、结构感知、标题与长度分块见[功能文档](/zh-Hans/guides/knowledgebase/chunking)。本提案不表示这些新配置或接口已经可用。

## 当前基础与缺口

| 已有能力                                              | 待补齐部分                                       |
| ----------------------------------------------------- | ------------------------------------------------ |
| `auto` / `structure-aware` 普通文本策略及共用执行入口 | 将同样的结构边界能力用于现有父子分块             |
| `parent-child` 的全文/段落父块及子块切分              | 类型化的父级/子级边界选择和对应 UI               |
| 已有文档 estimate 优先复用解析快照                    | 显式严格快照模式：快照不可用时保证不再调用解析器 |
| 结构、来源和 Token 诊断                               | 真实解析输出的结构保真修复及固定样本质量评估     |

当前 `POST /api/knowledge-document/estimate` 在已有快照缺失、过期或损坏时仍可能回退到完整解析。已有 `rechunk` 处理模式不等于 estimate 已提供严格只读、禁止外部解析的选择。

## 父子分块边界

扩展已有 `parent-child`，不新增“自动父子”“标题父子”等重复 provider：

- 父块保留全文模式；分段模式可选择标题/结构边界。缺省新字段时继续旧分隔符行为。
- 子块仅在所属父块内选择长度、标题、结构或自动边界，禁止再次嵌套父子策略。
- 使用共享合同中的显式 discriminator 表达边界。`parent.boundary` / `child.boundary` 是拟议字段位置，须在实现时统一类型、schema、归一化和 UI；不能仅保存未执行的字段。
- 全文父块不显示无效的父级切分参数。检索叶子的 Token 上限不能隐式切碎父级上下文；父级上下文预算保持独立。
- Token 二次切分后仍保持父子归属、顺序、章节和来源范围，子块不跨父块合并。

共享能力必须接入文档加载、预览和流水线，避免仅某一个入口支持新边界。

## 严格快照预览

在已有 estimate 的类型化输入或明确版本化的只读接口中增加“仅使用已有解析结果”选择：

1. 根据可信文档身份完成租户、组织、知识库和文件访问校验。
2. 核对解析快照的内容、提供者、参数和版本指纹。
3. 用尚未保存的分块配置执行共同切片逻辑，返回预览与实际策略诊断。
4. 快照缺失、过期或损坏时返回明确原因，不自动重新解析、不调用外部服务/模型、不写入新 chunk。
5. 不改变旧请求默认行为和返回结构；如需更丰富诊断，采用向后兼容版本或新的只读入口。

不新建第二套解析快照存储。重切缓存必须纳入有效配置和算法修订，不能因为解析快照相同就复用旧分块。

## 结构保真修复与实验

旧样例记录了以下问题，实施前先基于当前代码复现，已经修复的项只补回归证据，不重复改造：

- Markdown CRLF 标题在旧标题策略中的识别。
- DOCX 自动编号在转换后的保留。
- PDF 正文与图片混合片段被标为非文本，导致通用策略跳过切分。
- HTML/图片表格、复杂合并单元格和跨片段续表的能力边界。

转换器负责产出类型化结构，分块器消费明确证据，不通过文件名、显示名称或文本外观猜类型。外部转换器需要新增合同时，先发布兼容的共享合同，再适配插件和宿主。

质量实验使用固定文档与问答集比较长度、标题、结构和自动策略的召回、上下文质量、延迟和索引成本。语义相似度切分、自定义章节规则只有在证明收益后再单独立项，不是本提案默认实现项。

## 实施顺序

1. 明确父子边界合同、参数优先级、叶子 Token 与父级上下文预算，并补兼容测试。
2. 接入共用执行器和三个入口；前端只展示已经接通的选项。
3. 实现严格快照预览，验证权限和“零外部解析调用”的失败路径。
4. 复现并修复结构保真问题，补转换入口的样例回归。
5. 用固定数据记录质量与成本，再决定是否扩展策略。

## 验收条件

- 旧父子配置输出和归属保持兼容；新子块不得跨父边界或形成嵌套父子结构。
- 相同快照、配置和算法版本下，预览与共同执行阶段的正文、顺序、Token 和相对父子关系一致；随机 ID 与时间戳不作为比较依据。
- 严格模式在缺失/损坏/过期快照、越权或取消时不启动转换，不持久化 chunk；默认旧入口保留原有兼容行为。
- 模型最终 Embedding guard 导致的进一步切分单独验证，不将逻辑预览块数视为物理向量数。
- Unicode、代码缩进、表格行/表头、标题、来源范围及重复上下文有真实格式回归。
- 真实检索质量报告与单元测试结果分别记录，未执行项目不标为通过。
