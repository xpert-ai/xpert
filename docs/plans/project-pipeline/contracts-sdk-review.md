## 兼容性约定

- 本次未改变 JSON 协议版本或新增必填配置字段。已正确声明的配置保持可用；过去依赖继承属性而误通过的无效配置现在会被拒绝。
- `ProjectPipelineContribution` 和 `projectPipelineContributionSchema` 的 SDK 导入路径保持不变，Contracts 额外导出其唯一实现。发布 SDK 时必须配套包含该导出的 Contracts 版本，不能与旧 Contracts 混发。
- 目录查询结果是共享的不可变元数据。需要定制时先复制，并通过新模板版本重新注册；不允许修改已注册同版本定义。
- 不同来源共享纯 JSON 声明可以安全注册；共享同一个实时适配器实例不再允许。插件加载器应为不同作用域创建独立实例。同来源的重复发现保持幂等。
- 只提供 `snapshot` 的只读 Provider 仍然有效。提供动作执行时必须配对 `inspectAction`，有 `actions` 时必须提供执行接口；声明未来协议版本不会被误当作旧协议使用。
- 模板版本、扩展引用版本和宿主协议/能力版本各司其职。新增执行语义应声明宿主能力，由宿主明确支持；不要通过包版本、展示文字或业务名称推断能力。
- 历史业务快照与执行观察状态仍然分离。本次没有改动宿主执行状态、节点归属或在线数据。
