## 其他关键路径

- **反馈到候选：** 黄金标记、忽略和恢复可往返；真实客服反馈检查取得 9 条脱敏证据，生成建议后可回查对应事件。证据不足时创建按钮禁用。过期的检查指纹返回 409；同一检查的并发重试未重复创建建议。建议可以构建候选，再显式选择冻结数据集回放。
- **录入快照：** 导入 62 例 JSON，定位第 2 行无效风险，逐行修正后冻结。服务端返回的快照已自动选中，刷新后仍指向它；随后实际运行了上表第二次回放。
- **人工审批：** 在真实待签审记录上核对修改、评测、影响范围和签审标识；在隔离 PostgreSQL 中验证批准写入业务版本、批准后另建分阶段发布包及驳回。创建发布包不会移动生产指针，签审批次与实际评测不匹配时拒绝写入。
- **规则基线：** PBOM 的生产和来源规则指纹一致（阈值 0.85）；字段绑定来源受阻，保留 9 条生产绑定和 1 个模型版本；客服提供方不支持基线预览，但仍能查看生效版本并跳转到对应发布。
- **回滚：** 真实本地客服页打开 1.2.0 → 1.0.0 的确认框后取消，指针保持修订 2。实际回滚写入、阶段跳级拒绝与审计记录在隔离数据库中验证。
